2.1.0.25.115

Action: archives and every prover must run this release before GLOBAL frame 1,024,560 (not before 2026-11-07 02:16 UTC; #1258-#1262). Other changes need no operator action.

- A node's planner no longer rejoins a shard its operator just left, for one epoch; the join planner logs the hold; no operator action. (#1133)
- A node no longer fails to execute a child shard's frame when it arrives before the shard's imported state; such frames are held until the import finishes, with the hold's bounds logged; no operator action. (#1213)
- A proposer no longer splits off an empty shard that outputs can still reach; the split-proposer probe logs `withheld_empty_side`; no operator action. (#1214)
- On macOS, the node service uses a macOS layout; no operator action. (#1230)
- `qclient token shield` stops waiting for a batch whose shard has no provers, and says so; no operator action. (#1217)
- The node manager keeps its frame intervals through a late shard refresh; no operator action. (#1228)
- qclient finds users through the system user database; no operator action. (#1229)
- On macOS, the install script gives the qclient link its signature files; no operator action. (#1231)
- A worker can evict payload beside its own root index after a split; no operator action. (#1220)
- qclient prints results only by default; derivations show with -v; no operator action. (#1167)
- The slow-store warning names the cause the evidence supports, load or disk; no operator action. (#1234)
- Replacing a key or state file keeps its owner, so a sudo qclient no longer leaves root-owned files; no operator action. (#1235)
- The explorer lists the hosting node in its peers and releases counts; no operator action. (#1237)
- A bad row no longer stops the valid-shard set from refreshing; no operator action. (#1238)
- A node reports a start refused for an expected wait as waiting, with the event it awaits, so the manager no longer shows it as blocked; no operator action. (#1239)
- A seat confirmed just before an epoch boundary is no longer freed and rejoined by its own node on a stale view; no operator action. (#1241)
- Archive recovery waits out a GLOBAL sync in full, as answered replays no longer spend its budget; no operator action. (#1242)
- A slow worker reconcile no longer holds the prover tree sync and the committed GLOBAL view, so storage snapshots start on time on nodes with many seats; no operator action. (#1243)
- A session leader behind on a GLOBAL state sync gives its turn up at once, so the next leader proposes about 3 s sooner; no operator action. (#1245)
- The false `closing session's seal not recorded` warning, seen with the seal already on chain, is gone; no operator action. (#1246)
- The archive recovery batch line splits replay time by what it went to, and warns at most every 10 minutes when replays take 1 s a frame while workers wait; no operator action. (#1247)
- The low certificate share warning is judged against quorum over voters and no longer restarts on every frame at the threshold; no operator action. (#1248)
- A node's own vote echoed back before its batcher saw it no longer panics and stops the engine; no operator action. (#1249)
- Root's auto-update cron entry runs qclient only from the verified release under the install root, and only when root alone can write those directories; the macOS launchd daemon runs as the installing user and refuses a binary, config or environment file another user can write, naming the `chown` to run. To apply it, re-run the install (cron or launchd setup). (#1232)
- A node warns when one network group (IPv4 /24 or IPv6 /48) holds enough of a shard's seats that losing it would leave the shard at most one member above quorum, and says what to do when that group is its own site; the node manager shows a notice. (#1236)
- A missing app frame body is logged at info at 30 s and warns only after 10 minutes, with its real cost, and a per-shard delivery summary names the link or disk behind repeated stalls; no operator action. (#1250)
- Archives log one bounded line when their GLOBAL proposals carry under half the usual shard headers, naming the missing shards and why; no operator action. (#1251)
- The node manager's Coins tab no longer gives up on large legacy-coin listings after 120 s: it shows progress and fails only when nothing arrives for 120 s; no operator action. (#1252)
- Provers whose seniority storage-epoch proof kicks set to zero before epoch 1342 get it back at GLOBAL frame 1,024,560 (epoch 1423, not before 2026-11-07 02:16 UTC); archives and every node that executes GLOBAL frames must run this release before that frame. (#1258)
- From GLOBAL frame 1,024,560, a sealed shard's successor is seated from the shard's eligible provers at the next session pass, not from the committee its request fixed up to an epoch earlier. (#1259)
- From GLOBAL frame 1,024,560, a leaving allocation counts toward successor committees only if it was current when it left, so lapsed leavers no longer raise a committee's quorum beyond its voters. (#1260)
- From GLOBAL frame 1,024,560, a node's confirm signs the release it runs and GLOBAL records it; nothing is gated on it yet, and qclient confirms stay as before. (#1261)
- From GLOBAL frame 1,024,560, GLOBAL accepts presence reports, credits the committee voters they carry and records each signer's last signed frame; nothing is excluded until an epoch of this data exists. (#1262)
- A wallet or app submission that no peer can take is handed to this node's own engines of the application, or answered Unavailable so the sender resends, instead of failing as Unauthenticated; one bounded warn names what to check. (#1263)
- A node labels as many storage leaves ahead at once as its cores and memory allow (one per 4 CPUs and 16 GiB, at least two), and labels ahead any leaf whose estimate exceeds half the grace, so large hosts stop giving up snapshots of big leaves. (#1265)
- Log lines about a seat renewing without a storage registration now say its frames carry no storage attestation that epoch, instead of claiming a reward effect GLOBAL decides. (#1267)
- A worker idle because its operator is leaving the seat is reported as leaving, at info, instead of a warn about a lost seat or a reconfirm nothing can renew. (#1254)
- The Coins tab's legacy-coin read reports its last page when it arrives with the result, so its progress no longer ends one page short. (#1268)
- From epoch 1429 (frame 1,028,880), a replica key binds only the member and the leaf, so a leaf keeps its storage labels across epochs instead of relabelling each epoch. (#1269)
- A node resends its subscriptions to a peer when one of that peer's connections closes and others remain, so a worker restarted under the same peer id is no longer left without subscribed peers and held at its consensus start. (#1270)
- The `closing session's seal not recorded` warn names its scope: `scope=local` when this worker's GLOBAL view trails the node's latest frame by more than a seal takes to land, instead of always blaming the network. (#1271)
- A process exiting while a store closes no longer aborts with "pthread lock: Invalid argument": stores opened by the process are left open at exit after closes in flight finish. (#1272)
- The master and standalone workers on one host share one storage-job budget, so together they no longer hold more memory or label further ahead than the host allows; no operator action. (#1225)
- A shard's outputs in later blocks are delivered while an earlier block's output waits on a missing frame, and a held frame lacking the operation is fetched again; no operator action. (#1275)
- A worker replaying from an archive up to a session fence stops at the frames the fence discarded instead of failing every recovery attempt on them, and logs the hold; no operator action. (#1279)
- GLOBAL checks a shard frame header's window and output before the rest of it; no operator action. (fork merge, no PR number)
- An app shard refuses on arrival a submission that no frame of it could execute, instead of holding it in its pool; no operator action. (fork merge, no PR number)
