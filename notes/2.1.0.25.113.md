2.1.0.25.113

No action required from operators, except the first line if it applies to you.

- Only if you mint or shield with another node's config (such as a dormant prover's): pass `--submit-config <DIR>` for the node that submits; qclient now refuses before any fee quote or proof when the submitting node's peer key differs from the signing config's, naming both and the fix. (#1056)
- Archives keep proposing a shard whose stored frames ran past their 8,192-body window, so a shard far ahead is carried by GLOBAL again; archives log the backlog's start and end; no operator action. (#1057)
- GLOBAL proposals give their slot beyond the frame budget to the shard furthest behind, so shards past the budget are no longer left behind; the node logs when the budget starts and stops deferring tips and warns if a deferred shard waits past its bound; no operator action. (#1060)
- Nodes answer a new read-only `GetMintAuthorizationStatus` RPC: for a reward mint's receipt, whether its authorization was included, at which frame, the claim cap and why it is not yet claimable; the node logs `mint claim: no citable authorization yet` (rate-limited) when a claim finds no receipt; no operator action. (#1062)
- Storage epoch proofs get a deadline sized to the proof (up to 100 s) and are resent to one archive after another until the window ends, so a node on a slow uplink is no longer kicked for a proof it made in time; the node logs `storage epoch proof delivered` or `not delivered`; no operator action. (#1063)
- The retention pruner scans old versions without holding the store's commit lock, taking it only in short holds (about 100 ms), so commits and reads no longer stall for 9–18 s every 10 minutes on large stores; the node warns if a hold reaches 5 s; no operator action. (#1064)
- Archives wait for a finalized parent frame to publish before executing it, instead of executing it privately after 8 s, so archives no longer log `prover root MISMATCH` and stall GLOBAL; the wait logs its start, every 2 minutes and its end; no operator action. (#1065)
- A member seated by a successor walks its predecessor's sealed history from the engine loop at a bounded pace instead of one small batch per 10 s, so it can vote within seconds rather than minutes; the walk logs its start, progress and end with duration; no operator action. (#1067)
- Archives that leave `proofWorker.maxConcurrent` unset size their proof verifier slots to the machine (CPUs divided by `nativeThreads`, at most one per 3 GiB of available memory, 2 to 8) instead of a fixed two, so they keep up with GLOBAL's confidential operations; regular nodes keep two; no operator action. (#1068)
- Adds a one-time restoration of seniority that storage-proof kicks took from eight provers before epoch 1342; inactive until a later release sets its activation frame; no operator action. (#1070)
- The GLOBAL request-body pruner no longer forces a compaction after every 10-minute pass (about 480 MB rewritten each time, even on worker stores holding no bodies); it compacts only once pruned bodies reach 1 GiB, and its info line `pruned GLOBAL request bodies` reports `reclaim=deferred`; no operator action. (#1073)
- A node building a storage commitment reads only the replica nodes a frame opens instead of loading the whole replica (about 1.9 GB at peak for a 929 MiB replica, now about 4 MB), so regular nodes' memory no longer swings by gigabytes per frame and drives them into swap; stored replicas convert in place on first use; no operator action. (#1077)
