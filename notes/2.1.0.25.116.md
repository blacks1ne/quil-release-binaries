2.1.0.25.116

Action: provers should run this release well before epoch 1467 (GLOBAL frame 1,056,240, about 2026-11-10 19:45 UTC), so each certifies its label sectors before then; from 1467 a seat without a sealed registration sits out its shard and earns nothing (#1139, #1318). Archives should run it as soon as it publishes.

- A regular node deletes the stored frames of shards it no longer serves, so its store stops growing with them; no operator action. (#1280)
- Replay step timings read each thread's CPU time from its CPU clock, so a step's CPU time no longer includes part of the previous step; no operator action. (#1281)
- Storage labels are written to disk in bounded chunks instead of one write of up to about 1 GB per layer, so a node's store no longer stalls while it labels; no operator action. (#1266)
- GLOBAL can reseat a stalled shard session without the provers that went silent instead of waiting for its timeout; it stays off until a later release sets its activation frame; no operator action. (#1233)
- The shared worker thread pool gets 16 MiB stacks, so storage encoding no longer aborts with a stack overflow on large hosts; no operator action. (#1282)
- The node now judges app-frame stalls itself, each shard by three of its mean frame intervals, so the node manager no longer flags healthy slow shards; it logs each condition's start, repeats and end; no operator action. (#1244)
- `qclient node prover manage` and `prover status` show what a restart now would cost each seat: nothing, its storage share this epoch, or its shard; pick a moment when every seat says restart ok. (#1253)

- `qclient token custom-mint` now forms the mint from the token's deployed policy, so a paid mint of a payment-policy token no longer pays its settlement and then gets refused for carrying an authority signature; no operator action. (#1286)

- Wallet scans derive the wallet's keys once per scan instead of once per coin, so `token balance` and other confidential scans finish much faster on wallets with many coins; no operator action. (#1291)
