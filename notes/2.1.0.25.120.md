2.1.0.25.120

No action required from operators.

- A regular node gives up on an archive serving the GLOBAL prover tree too slowly (under 100 reads, 50 leaves or 512 KiB per second over 60 s) and pulls from another, so a slow archive no longer freezes its GLOBAL view for many minutes; no operator action. (#1352)
- A node drops a shared archive connection after requests in a row miss their deadline, so an archive that stops answering no longer fails every submission and read until restart; no operator action. (#1355)
- Replica stores compact evicted chunks only once garbage reaches about a quarter of the kept bytes, and evictions no longer reread kept chunks, cutting disk writes at each epoch boundary; no operator action. (#1356)
- A node whose storage epoch proof is refused sends it again only at its retry queue's next round (jittered 5-60 s, soonest window first) instead of to every archive at once, cutting proof traffic; one line per ended window counts proofs published, sent, accepted and refused; no operator action. (#1357)
- Archives carry held storage epoch proofs soonest window end first and, when their share is full, make room for a proof due sooner by dropping expired or later-due ones, so settlements due now are no longer refused behind proofs due an epoch later; archives should run this release. (#1359)
- After lowering the worker count, a node's surplus leave sheds the draining workers' seats first, so those workers stop instead of idling a kept worker and draining forever; no operator action. (#1360)
- A node proves all of a member's due seat settlements for an epoch in one proof instead of one per seat, so the burst at each settlement window no longer fills the archives' ranks and archives stop refusing submits for 10-25 minutes after each boundary; no operator action. (#1361)
- GLOBAL frame handling is more robust; no operator action. (b3d33ef7)
- Gossiped frame decoding is tightened; no operator action. (a3caa597)
- Onion routing is more robust; no operator action. (e729fd36)
- Explorer: kicked allocations show as kicked, and the kicked-provers list fills. (#1364)
- A node whose shard messages find no peers logs one warning per outage with five-minute summaries, instead of a warning per retry; it no longer retries while it has no peers. (#1365)
- Shard info no longer lists a parent shard after it splits away, so health checks and clients stop counting it as a served shard. (#1366)
- A synced node no longer raises the GLOBAL state sync health condition for routine pulls; only an install running over 10 minutes raises it, with a line naming the overrun. (#1367)
